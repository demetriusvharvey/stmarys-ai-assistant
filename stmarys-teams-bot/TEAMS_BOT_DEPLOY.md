# Teams Bot Deployment Guide

The bot is fully built (`lib/src/` is compiled and ready). This guide covers the two paths to get it live.

---

## Option A — Local dev tunnel (test in minutes, no Azure needed)

Requires: Node.js, Teams Toolkit VS Code extension or `teamsapp` CLI, ngrok or Dev Tunnels.

1. **Start the Next.js app**
   ```
   cd C:\Users\dharvey\stmarys-ai-assistant
   npm run dev
   ```

2. **Start the bot**
   ```
   cd stmarys-teams-bot
   npm install
   node lib/src/index.js
   ```
   Bot listens on port 3978 by default.

3. **Expose port 3978 publicly**
   ```
   ngrok http 3978
   ```
   Copy the HTTPS URL (e.g. `https://abc123.ngrok.io`).

4. **Fill in `env/.env.local`**
   ```
   BOT_DOMAIN=abc123.ngrok.io
   BOT_ENDPOINT=https://abc123.ngrok.io/api/messages
   ```
   BOT_ID and TEAMS_APP_ID come from step 5.

5. **Register the bot in Azure**
   - Go to portal.azure.com → Create resource → Azure Bot
   - Set Messaging endpoint to your ngrok URL + `/api/messages`
   - Copy the App ID → paste as BOT_ID
   - Under Channels → add Microsoft Teams

6. **Upload the app to Teams**
   - Zip the contents of `appPackage/` (manifest.json + both PNGs)
   - In Teams → Apps → Manage your apps → Upload a custom app
   - Select the zip

7. **Set STMARYS_AI_API_URL in bot env**
   The bot calls the Next.js API. For local dev:
   ```
   STMARYS_AI_API_URL=http://localhost:3000/api/ai-tools/answer-question
   ```

## Option B — Azure App Service (production)

Requires: Azure subscription, `az` CLI, Teams Toolkit.

1. Run `teamsapp provision --env dev` from the `stmarys-teams-bot/` folder.
   This provisions the Azure Bot, App Service (B1), and registers the app.

2. Run `teamsapp deploy --env dev` to push the compiled bot.

3. Set these env vars in the Azure App Service Configuration:
   ```
   STMARYS_AI_API_URL=https://<your-nextjs-app-url>/api/ai-tools/answer-question
   INTERNAL_ADMIN_SECRET=<same value as in .env.local>
   CLIENT_ID=<Azure Managed Identity client ID>
   ```

4. Publish the Teams app via the Teams Admin Center for org-wide rollout.

---

## Required env vars summary

| Variable | Where to get it |
|---|---|
| BOT_ID | Azure Bot resource → App ID |
| TEAMS_APP_ID | Generated by Teams Toolkit during provision |
| BOT_DOMAIN | Your ngrok domain or Azure App Service hostname |
| BOT_ENDPOINT | BOT_DOMAIN + `/api/messages` |
| STMARYS_AI_API_URL | URL of the Next.js `/api/ai-tools/answer-question` endpoint |
| INTERNAL_ADMIN_SECRET | Same value as in Next.js `.env.local` |
